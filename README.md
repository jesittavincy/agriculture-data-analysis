# Agriculture Data Analysis

## Overview

This project focuses on analyzing Indian agricultural crop production data using Python and Pandas. The analysis includes data cleaning, exploratory data analysis, and visualization to understand crop production, yield, area, seasons, and state-wise production.

## Dataset

The dataset contains agricultural information including:

- State
- District
- Crop
- Year
- Season
- Area
- Production
- Yield

The original dataset contains 345,407 records and 10 columns.

## Analysis Performed

- Data cleaning and preprocessing
- Missing value handling
- Duplicate removal
- Crop-wise analysis
- State-wise production analysis
- Yield analysis
- Data visualization

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook / Google Colab

## Project Files

- `agriculture.ipynb` – Jupyter Notebook containing the complete analysis.
